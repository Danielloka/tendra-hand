# Simulation

**MuJoCo** models and tools for simulating the hand and running its **digital twin** (a simulated copy that mirrors, and can drive, the real hand).

Planned contents:
- A converter: `hardware/robot_description/fusion_export/` to cleaned URDF and MuJoCo **MJCF**
- MJCF models with joints, actuators and (later) tendons
- Viewer and test scripts (joint sliders, trajectory playback)

NVIDIA Isaac Sim/Lab may be added later on a machine with an NVIDIA GPU.
