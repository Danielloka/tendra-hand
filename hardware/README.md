# Hardware

Everything physical about Tendra Hand: mechanical design, printable parts, electronics and the robot description.

| Folder | What goes there |
|---|---|
| `cad/` | Source CAD: Fusion 360 `.f3d` files plus neutral **STEP** exports (STEP opens in any CAD program) |
| `print/` | Ready-to-print **STL/3MF** files and print settings (material, infill, orientation) |
| `electronics/` | Wiring diagrams, pinouts, power budget, bill of materials (BOM) |
| `robot_description/` | Robot model files (URDF) exported from CAD, used by `sim/` |

Hardware changes are logged in `research/log.md`.
