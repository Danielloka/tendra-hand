# Research archive

This folder is for historical and intermediate material that is useful to keep but should not sit in the main project tree.

## What belongs here

- Dated Claude / agent-team studies and exploratory design sessions
- Intermediate CAD experiments and generated geometry that has not (yet) been promoted into `hardware/` or `sim/`
- Long working notes that have already been summarised into `research/log.md` or the main design files

## Current contents

The `cloud-claude/` directory at the repository root contains the active agent-session studies. Those folders are working material; accepted results are meant to move into the normal places (`research/log.md`, `hardware/`, `sim/`, etc.).

Over time, completed or superseded session folders can be moved under this `archive/` tree so the root stays focused on the live project.
