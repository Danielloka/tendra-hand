# cloud-claude/

Research done by Claude in cloud sessions (claude.ai/code), usually by an agent team. Each study gets
a dated folder with a `README.md` (summary and recommendation first) and one report per agent.

These are **studies, not decisions**. Accepted results move into the real places: `research/log.md`,
`research/references/`, `hardware/`, `sim/`, and `CLAUDE.md`.

| Folder | Topic |
|---|---|
| [`2026-11-04-v1-wrist/`](2026-11-04-v1-wrist/README.md) | A 2-DOF wrist (bend + wave) for V1 that passes all 16 tendon loops (32 strands) cleanly |
| [`2026-11-09-v2-hand-cad/`](2026-11-09-v2-hand-cad/README.md) | "V2 concept": full hand, thumb, wrist and forearm in CadQuery with one 7 mm drum on every joint; geometry works, tendon housing must change |
| [`2026-11-14-data-glove/`](2026-11-14-data-glove/README.md) | "Tendra Skin": slim magnetic data glove (magnet + 3D Hall per joint, open palm) for recording demos; electronics package, KiCad wrist-pod schematic, glove + dongle firmware |
