# Electronics

Wiring, pinouts and power for the hand.

**Current setup (Phase 1):** ESP32-S3-N16R8, 8x 28BYJ-48 steppers, 8x ULN2003 drivers, separate 5 V / 2 A motor supply.
**Planned:** Feetech SCS0009 smart servos on one bus via an FE-URT-1 adapter.

The authoritative pin map lives in `firmware/` (config header) and `CLAUDE.md`. Keep diagrams here in sync with it.
